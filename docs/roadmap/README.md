# Cosa c'è in questa cartella

- **`STATO.md`** — dove siamo adesso: passo in corso, fatto finora, questioni aperte. Si
  aggiorna a fine sessione, prima del merge. È incluso in cima al `CLAUDE.md` di radice.
- **`METODO_E_FASI.md`** — il piano: ordine delle versioni (V1–V5) e come si lavora passo per
  passo. Non contiene dettagli tecnici di fase.
- **`note-tecniche.md`** — magazzino di dettaglio tecnico per versione, da consultare
  all'inizio di ciascuna fase e da rivedere in quel momento: non è specifica congelata.
- **`note-dati-sorgente.md`** — anatomia della sorgente EC50 (foglio Google), rilevata
  ispezionando il foglio reale: materiale di progetto per la fase V2.1.
- **`consolidamento-versione-paper.md`** — piano per archiviare una versione che riproduce i
  numeri citati dal paper, senza toccare l'aggiornamento automatico dei dati.
